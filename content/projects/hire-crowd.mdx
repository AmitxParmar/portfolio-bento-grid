## Overview

HireCrowd is a comprehensive hiring platform designed to bridge the gap between job seekers and recruiters. It features a robust ATS (Applicant Tracking System) that allows recruiters to manage the entire hiring lifecycle from a single dashboard.

Key focus areas:
- Seamless candidate experience
- Efficient recruiter workflow
- Real-time application tracking
- Scalable state management

## Technical Challenges

<ChallengeCard
  title="Efficient Data Pagination"
  problem="Loading thousands of job postings caused severe UI lag and high server response times as the dataset grew."
  solution="Implemented cursor-based pagination on the backend and utilized React Query's useInfiniteQuery alongside the Intersection Observer API on the frontend."
  result="Sub-50ms interaction latency with zero layout shift during discovery."
/>

<ChallengeCard
  title="Secure Multi-Tenant Access"
  problem="Recruiters and applicants share the same backend, requiring foolproof separation of data and privileges."
  solution="Designed a custom RBAC middleware that validates JWT claims against resource ownership and role permissions on every request."
  result="Zero reported privilege escalation vulnerabilities during testing."
/>
