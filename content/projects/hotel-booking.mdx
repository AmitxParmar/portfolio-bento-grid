## Overview

MERN Hotel Booking is a robust platform built to handle complex reservation workflows. It emphasizes security through HttpOnly cookies and operational integrity with advanced availability logic.

Key focus areas:
- Secure, XSS-resistant authentication
- Real-time double-booking prevention
- Comprehensive administrative controls
- Optimized media handling

## Technical Challenges

<ChallengeCard
  title="Complex Date Availability Checking"
  problem="Preventing double-bookings requires complex querying to check if a room is available for a requested date range across all existing reservations."
  solution="Designed advanced MongoDB aggregation pipelines to filter rooms that have overlapping booking dates with the requested period."
  result="100% reliable availability checks with zero double-booking reports during testing."
/>

<ChallengeCard
  title="XSS-Resistant Sessions"
  problem="Storing JWTs in local storage makes them vulnerable to cross-site scripting (XSS) attacks."
  solution="Implemented a secure session pattern using HttpOnly cookies for JWT delivery, ensuring the token is inaccessible to client-side scripts."
  result="Significantly improved security posture against session hijacking."
/>
